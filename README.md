## ⚙️ Cấu hình dự án
- **Ngôn ngữ lập trình:** Kotlin
- **Môi trường phát triển (IDE):** Android Studio
- **Kiến thức trọng tâm:** Activity Lifecycle, Explicit Intent (Intent tường minh).

## 🏃 Hướng dẫn chạy ứng dụng (Run App)
1. Tải toàn bộ mã nguồn về máy và mở bằng **Android Studio**.
2. Đợi hệ thống tự động thiết lập và tải các thư viện cần thiết (Sync Gradle).
3. Khởi động thiết bị giả lập (Emulator) hoặc cắm cáp kết nối điện thoại thật.
4. Nhấn nút **Play** màu xanh trên thanh công cụ (hoặc dùng tổ hợp phím `Shift + F10`) để cài đặt app lên máy.
